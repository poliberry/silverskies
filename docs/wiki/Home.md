# Silver Skies

Silver Skies is two native desktop weather apps built from one Rust codebase:

| | **Silver Skies** | **Silver Skies Pro** |
|---|---|---|
| For | Anyone who wants a calm, clear forecast | Weather enthusiasts, chasers, spotters, meteorologists |
| Look | Material 3 Expressive: rounded cards, colours from the sky | A financial-terminal workstation: black, amber, dense data |
| Forecast | Current conditions, hourly, 7-day, summaries | Everything in Silver Skies, as dockable data panes |
| Radar | One looping radar map | Multi-layer radar, NEXRAD single-site, storm cells, 3D radar volume over terrain |
| Severe weather | Alerts with plain-language details | Alerts, SPC outlooks and discussions, storm cells with tornado/hail signatures, storm reports, tropical cyclones, forecast soundings |
| Control | Search bar that understands questions | A command line (`:`) and function keys, plus menus |

Both run on **Windows, macOS and Linux**, work **anywhere in the world** (with extra detail where national services publish more), and need **no account or API key** to get started.
