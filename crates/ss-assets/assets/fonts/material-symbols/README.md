A subset (weight 500, optical size 24, unfilled) containing only the icons
Silver Skies uses, generated by the Google Fonts API (`icon_names=`). Icons are
addressed by their Private Use Area code points; see `ss_assets::symbols`.
To add an icon, regenerate the subset with its name added and add a constant.
